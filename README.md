## 先分清三个名字：Gemini Pro、Gemini Advanced、Google AI Pro

查资料的时候很容易被名字绕晕，这里一次理清：

- **Gemini 3.1 Pro** 是模型，谷歌现在的旗舰款，100 万 token 上下文窗口。
- **Google AI Pro** 是订阅套餐，19.99 美元/月。这个套餐历史上叫过 Gemini Advanced，也叫过 Google One AI Premium，都是同一个东西改名。
- 套餐分四档：免费版、Plus（4.99 美元）、Pro（19.99 美元）、Ultra（99.99 美元起）。

如果你看到一篇讲“Gemini Advanced 值不值”的文章，先看日期。这个名字已经弃用，旧文章里的额度、存储和价格大概率对不上了。

**Flow 积分没有公开的单次消耗价。** 谷歌只说“不同功能和模型消耗不同”，能确认的是生成失败不扣积分，用完就得等下月或加购。所以别信任何“每月稳定出 X 条视频”的精确说法，第一个月自己看积分表估。

**YouTube Premium Lite 和 Home Premium 是最容易被忽略的部分。** 这些服务单独订加起来不是小数目，也是这套餐区别于 ChatGPT Plus 和 Claude Pro 的核心——那两家卖的只是模型使用权，谷歌卖的是模型加一堆你本来可能在付钱的服务。

名单里还有 Lyria 3 音乐生成、Jules 编码代理的更高额度、Google Antigravity 入门权限。这些都是好东西，但对只想要个更好聊天机器人的人来说基本等于不存在。这正是这套餐的软肋：最贵的部分，恰恰是多数订阅者从头到尾没打开过的。
